各機能へのアクセスはこちらから

🌐 MCPサービス管理

MCPサービスの登録、編集、削除を行います。サブドメインの設定と複数のアプリを管理できます。

👥 接続アカウント管理

MCPアプリに接続するアカウントの登録、編集、削除を行います。Bearerトークンの発行が可能です。

📦 テンプレート管理

APIアプリの標準テンプレートとカスタムテンプレートを管理します。テンプレートからアプリを簡単に作成できます。

🔐 Variables管理

API Keyなどの秘匿情報を変数として管理します。アプリやCapabilityで{{変数名}}の形式で参照できます。

📚 Resources管理

LLMに提供するグローバルなリソースプールを管理します。ポリシーやドキュメントなどをMCP経由で配信できます。

📋 接続ログ

MCPサービスへの接続履歴を確認できます。監査やトラブルシューティングに活用できます。

🔑 管理者アカウント管理

Web管理画面にログインできる管理者アカウントの登録、編集、削除を行います。
